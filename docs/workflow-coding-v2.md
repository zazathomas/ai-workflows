# Agentic Coding v2 workflow

`coding-v2` is the default bundled workflow for the `agentic` CLI.

Stages:

1. DISC-00 Discover / Safety
2. SCAN-05 Consequence Scan
3. SPEC-10 Specify
4. PLAN-20 Plan
5. BUILD-30 Build
6. VERIFY-40 Verify
7. REVIEW-50 Review
8. DOC-60 Document
9. SHIP-70 Ship

M1 enforces forward completion with evidence and implements `DISC-00 -> SCAN-05` as the vertical-slice smoke path.
