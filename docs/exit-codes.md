# Exit codes

- 0: success
- 1: general failure
- 2: usage error
- 3: validation failed
- 4: transition blocked by workflow policy
- 5: unresolved blocker exists
- 6: approval required
- 7: task not found / no current task
- 8: lock timeout
- 9: command run failed
- 10: repo hygiene warning escalated to failure
